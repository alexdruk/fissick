Privacy

What Fossick does with your data — the short version: nothing

Everything stays on your computer

Fossick is designed from the ground up to run entirely on your machine. Your photos, videos, location history, and personal data are never uploaded to any server, never transmitted over the internet, and never seen by anyone other than you.

This isn't a policy that could change — it's an architectural fact. Fossick has no server to send data to. It doesn't make network requests during processing. It works completely offline once installed.

You can verify this

If you want to confirm that Fossick isn't making network requests, you can run it with your network turned off. Everything — processing, maps, place name lookups, trip detection — works without an internet connection. The map tiles, place database, and all processing logic are bundled inside the app.

What data Fossick stores, and where

Fossick creates a local database on your computer that stores an index of your photos and location data. This allows the app to be fast — instead of re-reading all your photo files every time you open it, it reads from this database.

What's storedWhereWhy
Photo metadata (filenames, dates, GPS, status)Local SQLite database on your Mac or PCFast browsing and search without re-reading files
Location history pointsSame local databaseEnables the map, trips, and places features
Your processed photo filesWherever you pointed Fossick (your Takeout folder or export folder)The fixed EXIF data needs to live somewhere
Processing state (for resume)A small file in your user data folderLets you resume interrupted processing

The database is stored in the standard application data folder on your system:

  • macOS: ~/Library/Application Support/Fossick/
  • Windows: %APPDATA%\Fossick\

You can delete this folder at any time to completely remove all Fossick data from your computer. The folder does not contain your actual photos — only the index.

No telemetry or analytics

Fossick does not collect crash reports, usage analytics, or any other telemetry. There are no tracking pixels, no analytics SDKs, and no "phone home" calls. When you close Fossick, nothing leaves your computer.

One optional network call

Fossick may check for a schema update on launch — a small file on GitHub that describes the current Google Takeout sidecar format. This is entirely optional, user-visible (you'll see a prompt), and contains no personal information. It exists so that if Google changes their export format again, you can get the fix without downloading a new version of Fossick. You can decline this check; it doesn't affect any Fossick features.

Licence verification

When you enter your Fossick licence key, the app makes a single verification call to Gumroad (the payment platform) to confirm the key is valid. This call sends only the licence key — no personal data, no photo information. After the key is verified, it's stored locally and no further network calls are made for licensing.

Open source dependencies

Fossick is built using open source components, including ExifTool (for writing photo metadata), Leaflet.js (for maps), and SQLite (for the local database). None of these components make network requests or collect data.
